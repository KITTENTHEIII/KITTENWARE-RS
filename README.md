## Installation

You can either download the precompiled executable or build the project yourself from source.

### Option 1: Download the executable (Recommended)

1. Navigate to the [Releases](../../releases) page.
2. Download the latest `.exe` file.
3. Run the executable to start the application.

No additional setup is required.

### Option 2: Build from source

If you prefer to compile the project yourself, you'll need to install the [Rust programming language](https://www.rust-lang.org/tools/install).

Once Rust is installed:

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
cargo build
```

Cargo will automatically compile the project and generate the executable in the `target/debug` directory.
